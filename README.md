## Pet Clinic Quality Engineering Hackathon

A team hackathon completed during Sparta Global training, focused on establishing and demonstrating quality processes for a Pet Clinic web application and REST API.
### Project Scope
- Define acceptance criteria, review standards and defect workflows.
- Test the UI, API, accessibility and security.
- Automate quality checks through a shared pipeline.
### My Role: API Testing
Testing owner, pet and visit endpoints, checking input validation and record relationships, and contributing automated tests and OpenAPI schema validation.
### Technologies
Java · Spring Boot · Angular · Swagger/OpenAPI · Playwright · GitHub Actions
